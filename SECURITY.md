# Security Policy

This is the Codekunde-maintained fork of Buttercup Desktop. The original Buttercup project is no longer maintained, so please do not send reports to the upstream `buttercup/dossier` policy.

## Supported versions

Only the latest release on the [releases page](https://github.com/codekunde/buttercup-desktop/releases) receives security fixes. Please update before reporting.

## Reporting a vulnerability

Please report vulnerabilities privately. Do not open a public issue.

- Email: [buttercup@codekunde.net](mailto:buttercup@codekunde.net)
- Include the affected version, your operating system, and steps to reproduce.

## What to expect

This project is maintained by one person in their spare time, so responses are best-effort:

- Acknowledgement within 7 days.
- A fix or mitigation plan as soon as the issue is confirmed.
- Credit in the changelog, if you want it.

## Scope

Issues in this repository (the desktop app) are in scope. Problems in the underlying `buttercup-core` library, in third-party services such as Dropbox, Google Drive or WebDAV servers, or in your own vault password choices are outside it, though I will still pass on what I can.
